# 樱刃工坊 Sakura Edge Studio

给《我的世界》Forge 1.20.1 的拔刀剑模组 **SlashBlade: Resharped（拔刀剑：重锋）** 做自定义刀的桌面工具。

不需要写 Java，也不需要编译：填完参数点「导出 jar」，扔进 `mods/` 就能在创造模式「抜刀剣」页看到自己的刀。

## 一、怎么用

1. 解压 `樱刃工坊-Windows-x64.zip`，里面 `SakuraEdgeStudio-win32-x64` 整个文件夹一起解压，不要只拿 exe。
2. 双击文件夹里的 `SakuraEdgeStudio.exe`。
3. 左边刀库默认有三把示例刀（无铭 / 白夜 / 绯樱），可以直接改成自己的，也可以点「＋ 新建刀」。
4. 右边 6 个页签：

| 页签 | 作用 |
| --- | --- |
| 基础 | 刀 ID、中英文名、命名空间、版本 |
| 属性 | 攻击力、耐久、不可损坏、拔刀术 SA、连段入口、**刀的状态**、**附魔编辑器（原版 40 个附魔中文下拉）**、特殊效果 |
| 渲染 | OBJ 模型 + PNG 贴图（可导入自己的）、**内置刀模（自绘 katana / 原版 agito / 原版 yamato）**、内置五套贴图、**模型分组自检**、召唤剑颜色、携带姿态 |
| 配方 | 新造刀 / 从旧刀强化（材质、核心、击杀数、炼数、耀魂要求） |
| 校验 | 逐项检查 + 一键导出 |
| 设定 | 拔刀剑机制速查：SA、连击、附魔增效、刀的状态、特殊效果、战斗能力、OBJ 分组规范 |

5. 渲染页签里有两个「内置」素材组：
   - **内置刀模**：`樱刃 katana（自绘）`（程序化生成，8 组齐全）、`讨骸刀 · 无尾（3mf 打印件装配）`（你提供的 3mf 拆件按组装图链式拼成整刀，再用装配剖面放样成 1719 面低模）、`讨骸刀 · 无尾（原版模型）`（用原版 `agito.obj` 的刀型改色：黑钢刀身 + 青绿刃口 + 白缠柄黑菱 + 黑鞘，与官方刀手感一致）、`讨骸刀 · 无尾（自绘像素版）`（早期从零捏的低模，像素风）、`原版 · 神裂 agito`、`原版 · 阎魔 yamato`（直接取自 SlashBlade: Resharped 的 `assets/slashblade/model/named/`，可直接当参照物，把自己的模型往上套）
   - **内置贴图**：`白夜`/`月影`/`绯樱`（工坊自绘三配色）、`讨骸刀 · 无尾`（`mubi.png`，128×512：原图重绘区 + 鞘漆区 + 白缠柄区）、`原版 · 神裂`（`agito_false.png`）、`原版 · 阎魔`（`yamato.png`）
   - 原版素材版权归原作者，工坊只是打包进来做比对，别单独二次分发
   - **刀模调整**：不想装 Blender 也能改模型——刀身长度 / 宽度 / 弯度 / 刀柄长度 四根滑杆直接改顶点（分组和 UV 不动），调完「导出 OBJ」「导出贴图」即可用；详见 `自己做刀模-不用Blender.md`
6. 中间是 3D 实时预览，拖拽旋转、滚轮缩放，三种舞台模式：
   - 「物品栏姿态」：物品栏图标视角（`item_blade` 组）
   - 「手持姿态」：第三人称持握（`blade` + `sheath` 组）
   - 「角色背负」：带一个方块小人，按 `carry_type` 把刀挂到身上（横背 / 腰间 / 斜背 等），用来确认挂点
   - 挂点数值取自原版 `LayerSlashBlade.renderBack`（颈部锚点、肩侧 x、身后 z、1/140 显示比例），并按本工具刀模的枢轴做了对齐；下方滑杆可 X/Y/Z、RX/RY/RZ、长度 实时微调，改完只影响预览，不影响导出

## 二、自己做模型

**首选：顶栏「建模器」**（v1.2.0 起）。不用装 Blender，参数化生成一把完整的拔刀剑，直接写回当前这把刀。

打开后是四栏：顶栏工具 / 左分组树 / 中三维视口 / 右参数面板。

- 顶栏：`正视` `侧视` `俯视` 切视角，`原版基准` 显示原版尺寸的刃线（青色两条线，调参跑偏时一眼看出差距），`网格` 开关，`导出 OBJ` `导出贴图` `写入这把刀` `关闭`
- 左栏：8 个组按 mcmod 规范命名（`blade` 已含镡与柄、`sheath` / `effect` / `blade_damaged` / `blade_fragment` / `item_blade` / `item_damaged` / `item_bladens`），勾选框控制显隐，点行选中（选中会在视口描青边），右侧显示面数
- 中栏：空白拖动＝旋转视图，滚轮＝缩放，点部件＝选中；视口默认浅色背景（暗色刀贴图也能看清），「视图」菜单可切深色并记住选择；选中带黄色描边
- 右栏：15 个滑杆（刀身长度/刃宽/厚度/上翘/头尾收窄/刀尖收窄/分段数/柄长/柄首尾半径/镡两个半径/镡厚/鞘壁余量/鞘长占比）＋ 5 个预设（标准太刀 / 长太刀 / 短刀 / 大弯刀 / 重置）

**添加元素**（`编辑` 菜单，对标 Blockbench 的「添加元素」）：除了参数化的刀身部件，还能往刀上加装饰件——方块、圆柱、球、四棱锥、三棱柱、圆锥、圆环七种形状。每个元素在右侧有自己的一张卡片：位置 XYZ、尺寸（长/高/厚）、旋转 XYZ 数字框，加形状与贴图下拉（刀身 / 柄 / 镡 / 鞘 / 纯色）。新加的元素会沿刀自动错开摆放，拖黄色手柄也能直接改位置，`删除` 即移除。

`写入这把刀` 会把生成的 OBJ、配套贴图、参数一起写进当前刀，回到主界面立刻能看到手持 / 图标 / 背负三种姿态，并可通过「校验」页确认分组齐全。

坐标约定：镡在原点，刀尖朝 +X、柄在 −X，刃面在 XY 平面、厚度沿 Z——与原版拔刀剑模型一致，8 组位置重合，因此导出后直接能用，不需要在游戏里再挪位置。

出口三个：`导出 OBJ` 拿手搓的模型文件，`导出贴图` 拿 128×256 的四区贴图，`写入这把刀` 走工坊的 jar 打包流程。

不会 Blender 又想拿别的软件做：见 `自己做刀模-不用Blender.md`，水杉 Metasequoia（原版作者用的工具）、Blockbench + OBJ 插件、或拿原版当底模只改贴图。

## 三、导出的东西

**附属包 jar**（推荐）：纯数据模组，`modLoader=lowcodefml`，不含 Java 代码。

```
META-INF/mods.toml                               模组元数据（依赖 forge 47+ / 1.20.1 / slashblade）
pack.mcmeta                                      资源包描述（pack_format 15）
data/<ns>/slashblade/named_blades/<id>.json      刀定义（属性/渲染/附魔/状态）
data/<ns>/recipes/<id>.json                      合成与强化配方（slashblade:shaped_blade）
assets/<ns>/model/named/*.obj|png                刀模型与贴图（相同内容自动去重）
assets/<ns>/lang/zh_cn.json、en_us.json          刀名
```

安装：`mods/` 里放 **SlashBlade: Resharped 1.20.1** + 本 jar，进游戏后刀会在「抜刀剣」创造标签页（`creativeGroup` 已指向 `slashblade:slashblade`；改成 `minecraft:combat` 则出现在战斗用品页）。

**资源包 + 数据包**（备用路径）：资源包放 `resourcepacks/`，数据包放存档的 `datapacks/`，同样能加载刀定义，适合不想装额外模组的情况。

## 四、刀定义字段对照（想手改 JSON 时看这里）

```json
{
  "name": "命名空间:刀ID",
  "properties": {
    "attack_base": 8.0,
    "max_damage": 110,
    "slash_art": "slashblade:sakura_end",
    "root_combo": "slashblade:standby",
    "unbreakable": false,
    "sword_type": ["bewitched", "fierceredge"],
    "special_effects": ["slashblade:wither_edge"]
  },
  "render": {
    "model": "命名空间:model/named/xxx.obj",
    "texture": "命名空间:model/named/xxx.png",
    "summon_sword_color": 4282006271,
    "color_inverse": false,
    "carry_type": "pso2"
  },
  "enchantments": [{ "id": "minecraft:sharpness", "lvl": 3 }],
  "creativeGroup": "slashblade:slashblade"
}
```

- 拔刀术 SA：`slashblade:none|judgement_cut|sakura_end|void_slash|circle_slash|drive_vertical|drive_horizontal|wave_edge|piercing`
- 连段入口：`slashblade:standby|none|combo_a1|combo_b1`
- 刀的状态：`bewitched`（妖）、`sealed`（封印）、`fierceredge`（千杀）、`broken`（折断）、`edgefragment`（残刃）、`noscabbard`（无鞘）、`souleater`（噬魂）、`unbreakable`、`enchanted`
- 携带姿态：`none|default|pso2|ninja|katana|rninja`
- 特殊效果：目前重锋内置 `slashblade:wither_edge`（凋零性），其他由附属模组注册
- 附魔：原版 1.20.1 共 40 个（工具内已全部内置中文名，按 武器/工具/防具/弓/弩/钓鱼/三叉戟/诅咒 分组），重锋本身不新增附魔

## 五、OBJ 模型规范（mcmod 教程 5202）

模型必须放在原版刀模型同一位置、同一比例，**不要移动/缩放/旋转参考模型**，只做自己的刀身，并按组名拆开：

| 组名 | 用途 |
| --- | --- |
| `blade` | 第三人称刀身 |
| `sheath` | 第三人称刀鞘 |
| `blade_damaged` | 耐久低时的刀身 |
| `blade_fragment` | 断刃碎片 |
| `effect` | 蓄力时鞘口高光 |
| `item_blade` | 物品栏图标（完好） |
| `item_damaged` | 物品栏图标（损坏） |
| `item_bladens` | 无鞘图标（教程标注未知，可不做） |

工具里「渲染」页的**模型分组自检**会实时读 OBJ 的 `g` 行，缺哪个组一眼能看到。内置的 `katana.obj` 已经包含全部 8 个组，可以直接当草稿。

贴图建议 16/32/64/128 方形、像素风、无抗锯齿。

## 六、常见问题

- **游戏里刀不显示**：检查 `mods.toml` 里 `slashblade` 版本范围是否匹配你装的版本；检查 OBJ 是否有 `item_blade` 组。
- **创造模式找不到刀**：`creativeGroup` 写成 `slashblade:slashblade` 才会进抜刀剣页；重锋的创造标签由模组在启动时扫描所有 `named_blades` 注入。
- **配方不生效**：配方引用的是同一命名空间内的刀 ID，强化源刀必须先生成。
- **附魔写了没效果**：只认已注册的附魔 ID（原版 `minecraft:*` 或你装的其他模组附魔）；工具列表里标 ★ 的才是对拔刀剑真生效的。
- **想改刀但不想重新打包**：直接改 jar 里的 `named_blades/*.json` 即可，纯数据。
