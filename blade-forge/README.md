# Blade Forge · 拔刀剑建模器

独立的拔刀剑建模软件，不用 Blender，参数化生成一把完整的刀，按 mcmod 教程 5202 的 8 组合规。

## 启动
解压后双击 `BladeForge.exe`。免安装，不需要 Java，不需要 Minecraft。

## 界面
- 顶栏：新建 / 打开 / 保存 / 导出 OBJ / 导出贴图 / 导出资源包 / 生成附属包；菜单 文件·编辑·视图·帮助
- 左栏：大纲（8 组，点眼睛显隐、点名字选中）、贴图画布（可手绘，128×256 四区）
- 中间：三维视口。拖动空白旋转、滚轮缩放、点部件选中；上方按钮切正视/侧视/俯视、开原版基准、网格、线框
- 右栏：15 个参数滑杆、9 个预设 + 重置、附加件面板（含导入元素）、模型信息
- 底栏：文件名、选中组、顶点/面数、FPS、消息

## 三种改法（不用滑杆也能改）
1. **视口黄色手柄**：直接拖。刀尖手柄——左右拖改刀身长度、上下拖改上翘；中部手柄——上下拖改整体弯曲；镡手柄——上下拖改镡大小；柄尾手柄——左右拖改柄长。松手即生效，右侧滑杆会同步跳数。
2. **右侧 15 个滑杆**：精确数值，适合微调。
3. **预设**：标准太刀 / 长太刀 / 短刀 / 大弯刀 / 唐刀（直刃）/ 裂爪匕 / 巨剑 / 双刃剑 / 斩马刀 / 重置。预设会顺带把相机拉到合适距离，长刀不会被切掉。

## 附加件（叠加装饰，可多件共存）
「附加件」面板里 5 个按钮，点一下就往刀上加一件，每件都能改位置和大小，× 删除：

| 附件 | 视口颜色 | 落到哪个组 | 位置滑杆含义 |
|---|---|---|---|
| 镡纹章 | 金 | blade | 沿刀身滑动（0 在镡上） |
| 柄穗 | 红 | blade | 穗长（越右越长） |
| 鞘挂饰 | 银 | blade | 沿刀身滑动（默认鞘口） |
| 刀光 | 青 | effect | 光带起点（叠加发光，视口里会透亮） |
| 火花 | 琥珀 | effect | 光点分布起点 |

## 导入元素（挂自己的模型）
点「＋导入元素」选一个 `.obj` 文件，它就挂到刀上，成为第 6 类附加件：

- 自动归一化：不管原模型多大，导入后最长边统一缩到 30（编辑器单位），再用「大小」滑杆 0.15～3 倍放大缩小
- 「位置」沿刀身滑 0（镡）～1（刀尖），「高低」上下移到 -70～70（默认 26，漂在刀上方）
- 「分组」决定导出时并进 `blade` 还是 `effect`
- 元素 UV 统一采样贴图的青色区，进游戏是青色实体，不会被贴图拉花
- 工程里只存文件路径：`保存` 后再次 `打开` 会按路径重新读取；找不到原文件时该行标「缺失」，模型跳过不影响其它部分

附加件在视口里用彩色现算着色，方便看清；导出 OBJ 时会按上表并进 `blade` / `effect` 组，跟着刀一起进游戏。

## 贴图自定义（直接在贴图上画）
左侧「贴图」面板就是 128×256 的画布，鼠标（或触控笔）按住就能画：

- 8 个色块：青 / 亮青 / 钢灰 / 近黑 / 金 / 红 / 白 / 黑，点一下换色
- 「笔粗」2～26 像素；「橡皮」擦回默认图案（按下去画哪里就还原哪里）
- 「重置贴图」整张回到出厂
- 松手即生效：视口里的刀身、预览、导出用的 png 是同一张图，弧形的赤色刀身就是这么画出来的

画哪里的对应关系（预览上有三条竖线标着分区）：

| 贴图列 | 对应 |
|---|---|
| 1–55 | 刀身（左侧是刀背侧，中间渐变，右侧越靠刃越亮） |
| 56–87 | 柄缠 |
| 88–126 | 镡盘 / 鞘 |

沿纵向（上下）画就是沿刀身长度方向画，越靠上越靠刀尖。贴图用的是最近邻采样，画 1 像素在模型上就是硬边，想要平滑的效果就用大笔刷多叠几层。

## 快捷键
F 正视 · S 侧视 · T 俯视 · G 网格 · R 原版基准 · W 线框

## 8 组（名称固定，位置与原版重合）
`blade`（刀身+镡+柄）、`sheath`、`effect`、`blade_damaged`、`blade_fragment`、`item_blade`、`item_damaged`、`item_bladens`

坐标约定：原点在镡，刀尖朝 +X、柄在 −X，刃面在 XY 平面，厚度沿 Z。导入游戏不需要再挪位置。

## 一键生成附属包（直接进 mods）

> 只出「模型 + 贴图 + 基础注册」这一层。**SA / SE / 剑型 / 附魔 / 剑气颜色请在 SakuraEdge Studio（做刀的那套工坊）里设置**，两个软件分工：这里管形，那里管刀。

顶栏「生成附属包」，填几个字段就写出一个 `.jar`：

- **模组 ID**：小写字母/数字/下划线，字母开头（默认 `bladeforge`）
- **刀 ID**：注册用的短名（默认从工程名转写）
- **中文名 / 攻击力 / 耐久 / 版本**：进游戏后显示的刀名、`attack_base`、`max_damage`

生成的 jar 是**纯数据模组**（`modLoader="lowcodefml"`），不含 Java、不用编译，结构：

```
META-INF/mods.toml                        声明 modid + 依赖 forge / slashblade
pack.mcmeta                               数据包格式 15（1.20.1）
data/<modid>/slashblade/named_blades/x.json   刀定义（属性/渲染/创造标签）
data/<modid>/recipes/x.json                   拔刀剑合成配方（耀魂系列）
assets/<modid>/model/named/<modid>_x.obj|png 当前模型 + 当前贴图（含你画的）
assets/<modid>/lang/zh_cn.json / en_us.json  刀名
README.txt                                 安装说明
```

放进 `mods` 就能加载，刀出现在「拔刀剑」创造标签页，也能用拔刀剑 + 耀魂合成。每次生成都是当前工程的样子（模型、附件、贴图都带上）。

一次性多做几把刀：改「刀 ID」再生成一次，或把多个 jar 解压后合并 `data/<modid>/...` 与 `assets/<modid>/model/named`。

## 出口
- `导出资源包`：选一个文件夹，一次写四份：`名称.obj`（带 `mtllib` + 每组 `usemtl blade_tex`）、`名称.mtl`、`名称.png`、`使用说明.txt`。直接照着说明放进 `assets/<modid>/models` 与 `/textures` 就能被 mod 读到，不用自己写材质文件
- `导出 OBJ`：8 组的 Wavefront OBJ，组名就是上表的组名
- `导出贴图`：128×256 PNG（刃青 / 刀身钢 / 柄缠 / 镡盘 / 鞘）
- `保存`：`.bfm.json` 工程（参数 + 名称 + 附加件列表），下次「打开」接着改

## 注意
- 原版基准是固定尺寸（刀身 253 / 刃宽 10 / 上翘 22 / 柄 93）的两条青线，调参跑偏时拿它对位
- 刀身分段越高越圆滑，面数也越高；MC 里 3000～6000 面足够
